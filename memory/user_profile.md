Solo developer building GymBro (fitness tracking app: Express backend + mobile/web client). Treats the deployed DB as beta — fine to wipe and reseed from `pg_sql.txt` rather than write migrations. Writes fix lists in plain prose and expects the assistant to plan, ask upfront clarifying questions, then execute in phases with short progress updates.

**How to apply:** For large multi-item requests, ask clarifiers up front in one batch (they answer willingly), then propose a phase plan and check in between phases. Don't write migration scripts during beta unless asked. Keep updates brief.
